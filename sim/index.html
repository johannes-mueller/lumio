Lumio Simulator

A software stand-in for the 24×60 APA102 LED flower. The same show code that runs on the RP2040 is running here in WebAssembly.

auto-advance show active

Buttons

Hold to imitate a long press (≥ 1 s). Advance: short press = next show, long press = toggle auto-advance. Action is the per-show button.

Messages

Chat between the web page and the firmware over virtual USB. Show transitions are announced here, and anything you send is echoed back once it has been received.
